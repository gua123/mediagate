## 待发布改动

### 1. 「测试通过」不再显示成红色（2026-10-03 真机截图）

用户发来「编辑连接」页截图：`测试一下` 的结果是
`〔使用：已保存的密码〕测试通过：sftp://…（1209 ms）`，**却是橙红色**——量了一下文字像素是 `rgb(160,48,32)`，
正是 M3 的错误色（`#B3261E`）⇒ 一条**成功**消息被染成了失败色。

**根因**：界面用 `result.startsWith("测试通过")` 判断颜色，而真实文案开头是「〔使用：…〕」，
`startsWith` 永远为假 ⇒ 一律走失败色分支。

**改法**：
- 新增纯函数 `testOutcomeOf(result)` → `TestOutcome.PASSED / FAILED / NOT_APPLICABLE`（扫描全文，不再看开头）；
- 界面按结局上色：通过 = 深绿 `#1B5E20`，失败 = `colorScheme.error`，没有地址 = 中性色；
- 并且给结果**加 ✓ / ✗ 前缀**（不只靠颜色区分，色觉障碍用户也能分辨）；
- **单测把真机那串原文钉住**（`TestOutcomeTest`，4 例）。

**已知局限（待办）**：`testOutcomeOf` 仍是"按中文文案分类"——更彻底的做法是让 ViewModel 直接传类型化结果，
已记进待办；当前有单测兜底，文案一改测试就会红。
