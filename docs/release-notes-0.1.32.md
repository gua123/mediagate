## mediagate 0.1.32

### 按你的口径：测试成功=绿色，失败=红色

你上一张截图里「测试通过」是**橙红色**——那不是配色偏好，是我写错了一行判断：
界面用 `result.startsWith("测试通过")` 决定颜色，而真实文案开头是「〔使用：…〕」⇒ 永远判假 ⇒ 成功走了失败色。
（我从截图里量到那行字是 `rgb(160,48,32)`，正是 Material 的错误色。）

现在：

| 结果 | 颜色 | 标记 |
| --- | --- | --- |
| **测试通过** | **绿色**（深绿 `#1B5E20`） | **✓** |
| **测试失败** | **红色**（`colorScheme.error`） | **✗** |
| 还没填地址 | 中性灰 | • |

顺带把逐地址的三段耗时结果也统一了（原来成功用的是主题紫，现在也是绿色 ✓）。
另外给你留了个小改进：结果前带 **✓/✗ 符号**，不只靠颜色区分——色觉障碍或者截图被压缩时也一样看得清。

判定逻辑换成了纯函数 `testOutcomeOf`，并**把你截图里那串原文写进了单测**（以后文案一改，测试就先红）。
