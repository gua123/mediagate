## mediagate 0.1.55 —— 两条新需求：可设置"后台是否进画中画" + 通知栏控制上一集/下一集

### ① 设置 → 播放：切后台时是否自动进入画中画

新增「**播放**」设置区块，一个开关：

- **开**（默认，保持旧行为）：播放中切到别的应用会出现小窗；
- **关**：切后台只继续后台播放，**不弹小窗**；
- 两种情况下**通知栏与锁屏都照常可控**（播放/暂停/进度/上一集/下一集）。
- 开关在**进播放页时生效**（正在播的那一条要退出重进才换行为）。

### ② 通知栏（与锁屏）多出「上一集 / 下一集」

以前通知栏只有播放/暂停与进度，现在多了两个按钮：

- **上一集 / 下一集**：走的是**播放页自己的队列**——也就是说它遵守你选的**排序**与**循环方式**
  （文件夹循环时到末尾会回到第一个；随机档会随机跳）；
- 播放/暂停、进度拖拽、锁屏控制、耳机键都照旧；
- 实现上用的是会话的**自定义按钮 + 自定义命令**，没有伪造播放列表——单条列表上假装有 next 会让 Media3
  的状态一致性断言把服务带走（本项目踩过这类坑）。
