## 2. 复现步骤（新机器）

    cd /root/project/mediagate
    bash scripts/install-toolchain.sh          # 私有 JDK21 + SDK(platform 37.2/NDK r30/CMake) + Gradle 9.8.0 + wrapper 缓存
    bash scripts/build-whisper-android.sh      # 可选：重建 ASR native 库（不进 git）
    source scripts/env.sh
    ./gradlew :app:assembleDebug

## 3. 已知限制 / 待办

- **APK 体积**：debug 114 MB / release 69 MB，主要是 libvlc.so（46 MB）与 ffmpeg 系列（≈14 MB）。自用 sideload 可接受；若日后要瘦身，考虑改用 VLC 的精简 libvlc 变体或按需裁剪 FFmpeg 组件。
- **真机未验证**：当前环境无 Android 设备（adb 无设备），安装与运行验证留到用户真机（R15）。
- **Media3 FFmpeg 解码扩展**不引入（Maven 无该产物，需自建 NDK），软件解码统一交给 LibVLC——已写进 plan 第 2 章。
- **whisper native 库不进 git**：由 `scripts/build-whisper-android.sh` 重建，随 `.toolchain/` 与 `jniLibs/` 一起忽略。
- **未接的功能代码**：各模块目前只有骨架与依赖，业务实现从 M1 起逐里程碑补。

## 4. 与计划的偏差

| 项 | 计划 | 实际 | 原因 |
| --- | --- | --- | --- |
| Kotlin 插件 | AGP + Kotlin 插件 | **AGP 9 内置 Kotlin**，禁止声明 kotlin.android | AGP 9 行为变更 |
| compileSdk | 36 | **37.2** | 2026-09 的 androidx 强制要求 ≥37 |
| Android SDK | 公共只读 /opt/android-sdk | **项目私有 .toolchain/android-sdk** | 公共 SDK 只装到 36，且不改公共资源 |
| Media3 FFmpeg 解码扩展 | 可选叠加 | **不引入** | 该扩展不发布 Maven 包 |
