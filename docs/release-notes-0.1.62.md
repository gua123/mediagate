## mediagate 0.1.62 —— 亮度/音量手势灵敏多了：一次短滑就能从 100 到 0

### 原来为什么"只能调一点点"

竖直手势的换算原来是**整屏高度 = 整个量程**——手指滑一点点，值就只动百分之几，想从最亮调到最暗得来回拉好几次。

### 现在

有效行程压到**屏幕高度的约三分之一**（FULL_RANGE_FRACTION = 0.35）：

| 你的动作 | 结果 |
| --- | --- |
| 往下滑约 1/3 个屏幕高度 | 从 100% 直接到 0%（音量同理，200% 到 0） |
| 往上滑约 1/3 个屏幕高度 | 从 0 直接到顶 |
| 小幅滑动 | 仍然是微调（1% 屏高 ≈ 3% 音量/亮度） |
| 滑过头 | 夹在两端，不会越界 |

亮度与音量用的是同一条换算，所以两边手感一致；HUD 上的百分比还是实时跟着走。
