## mediagate 0.1.25

按你说的三件事做完：**极简模式 / 不弹控制也能横滑调进度 / 拖动时看预览缩略图**。

### ① 极简模式
档位芯片那一排最前面多了「**极简**」：一点之后，标题栏、内核、旋转、整排档位芯片全部收起，
**只留一条细细的进度条 + 播放/暂停键**，右下角一个「完整」可以随时切回来。选择会记住，下次播放还是极简。
（点画面仍可显隐这条细栏，和以前一样。）

### ② 不弹出控制也能左右滑动调进度
在画面上**横向拖动**即可调进度：
- **不会**弹出控制层，只在画面中央浮出一个小小的进度提示；
- 整屏宽横向拖动 ≈ ±3 分钟（短视频按"半片"封顶，免得一划就到头）；
- 松手才真正跳过去（想反悔就取消手势，位置不动）；
- 结果夹在 0..时长之间，时长未知时不乱跳。

### ③ 预览缩略图
拖动时中央提示里会显示**该时间点的画面缩略图**：按 5 秒一桶缓存最近 32 张，
同一段不会反复解码；**抽不到帧就只显示时间**（预览只是锦上添花，绝不影响拖动本身）。
