# 0.1.65 发布说明（草稿 · **尚未发布**）

> 这份是 0.1.64 之后攒下的改动草稿。按发版纪律：**能感觉到的改动**才发版；
> 0.1.65 的"能感觉到"的点就是一句——**播放页的内核按钮里多了「自研引擎」这一档**。

## 新：自研引擎第一次能在界面里点到

- 播放页右上角「内核」按钮从**两档互切**改成**三档轮转**：
  **Media3 → 自研引擎 → LibVLC → Media3**（LibVLC 已知跑不了时自动跳过它）。
- 「自研引擎」＝自己写的播放内核（C++17 + 自研 FFmpeg + AAudio），
  数据走我们自己的数据层 ⇒ **本地 / SAF / WebDAV / SFTP / FTP 是同一条路**。
- 切过去之前会先弹一句说明（**不做静默降级**）：自研引擎目前还**没有倍速与硬解档位**；
  缩放四档、音量（含 >100%）、外挂字幕、拖拽调进度都正常。当前倍速不是 1.0× 的话，切过去会**如实回到 1.0×**。
- 内核不支持的那些档位**不显示芯片**，但原因写在芯片行里（"自研引擎暂无倍速与硬解档位"），
  免得看着像"按钮丢了"。
- 想换回来：再点一次「内核」按钮轮转即可（位置、字幕、缩放都保持）。
- **默认内核仍是 Media3**：日常照常用，自研引擎这一档目前是"可试"。

## 顺带（0.1.64 之后攒的）

- **列表封面空闲预热**：打开目录先等 3 秒（多半还在翻），再按并发 2 慢慢把视频开头封面取回来，
  取到就刷新那一格；用户一操作立刻取消。
- **打开文件夹自动缓存**：进目录后台预取，单文件按段并发 4，一次 2 个文件，同样一操作就让路。

## 已知限制（自研引擎这一档）

- 没有倍速、没有硬解档位（软解走 FFmpeg，M5 补）；
- 内嵌字幕轨还没做（外挂 srt/vtt/ass 正常，由 App 覆盖层渲染，与内核无关）；
- 画中画 / 后台播放 / 通知栏控制沿用既有会话层，行为与旧内核一致（真机验证中）。
