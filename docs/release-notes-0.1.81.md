# 0.1.81 发布说明

> 0.1.81 修一个会让播放卡住的问题：**清空缓存之后播放视频一直转圈，网络也完全不动**。

## 原因

清空缓存以前只删了段文件，**没有作废"清空前还在跑"的段下载任务**。旧任务可能还卡在一个已经没用的请求上；
新播放要读同一段时，会接上这个旧任务一起等——没有新请求、没有带宽，界面就一直转圈。

## 修复

- 清空缓存时**换代**（epoch）：唤醒并作废清空前启动的全部段任务；
- 旧任务即使晚到，也不会再把段文件改名写回缓存（不会再"清空后又冒出来一段"）；
- 一并清掉临时文件（.tmp），避免清空后还占空间；
- 新播放改用新代际的任务重新取数据，不再等旧任务。

## 如果更新后仍然转圈

那说明问题不在缓存任务，而在**选路/网络层**。请到「设置 → 诊断与日志」复制或分享诊断信息发我
（里面有面包屑与最近日志），并告诉我：

- App 版本是否 0.1.81；
- 协议是 WebDAV / SFTP / FTP；
- 这条连接是局域网还是公网；
- 同一目录下**浏览列表是否正常**（能列出来，还是也卡）。

## 验证

- 新增回归：清空缓存时，清空前启动的旧读必须立刻作废，新读能正常拿到数据；
- 全量 **1370 用例 0 失败**；release 包 0.1.81 / versionCode 82。
