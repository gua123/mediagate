## mediagate 0.1.2

上一版（0.1.1）留下的"已知限制"这一版基本清空。

### 新增
- **通知栏 / 锁屏封面**：视频与音频都带上封面（用列表里已经生成过的缩略图，不会为了封面额外抽帧）。
- **音频同目录封面兜底**：文件里没有内嵌封面时，自动用同目录的 `cover.jpg` / `folder.jpg`
  （按通行文件名优先级，不会把歌词本、海报误当封面）。
- **分段缓存（降级链第二级）**：远端文件按 4 MB 分段落本地缓存。不支持随机读的协议
  （无 Range 的 WebDAV、无 REST 的 FTP）因此也能被拖拽 seek；支持随机读的也省掉重复过网。
- **TS 索引真正接进 App**：
  · 没有 PCR 的 TS 会在播放页如实提示「拖拽定位会不准」，并指出「修复时间戳」这条出口；
  · 拖拽松手后按索引把落点那一段（4 MB）预取进缓存，减少第一帧的等待。
- **SFTP 主机密钥指纹落库**：重启后仍然认识旧指纹（此前只存在内存里，冷启动等于重新 TOFU 一次，
  变更检测形同虚设）；设置页新增「已信任的 SFTP 主机密钥」，可逐条忘掉——服务器真的换钥时有复原路径。
- **whisper 模型官方 SHA-256**：三档模型都回填了官方校验和，下载校验从"只核大小"升级为强校验。

### 修复
- **模型下载镜像失效**：原来的镜像写法（`https://gh-proxy.com/<原始地址>`）已 404，
  App 内下载模型必然失败；改成"替换主机"的通行写法，默认 `https://hf-mirror.com`（实测可用）。
- **强制硬解终于有落地口径**：Media3 上没有官方"只能硬解"的开关，现在把软件解码器从候选里剔除；
  本机确实没有硬解时如实退回软解并提示（LibVLC 侧本来就是强制硬解）。

### 说明
- 包名与 0.1.1 相同（`io.github.gua123.mediagate`），可以直接覆盖安装。
- TS 索引**没有**替换 Media3 的 seek 实现（那需要 fork 它的 SeekMap），
  索引的作用是"把拖拽落点附近的数据预热好"，因此不宣称"毫秒级拖拽"。
