## mediagate 0.1.31 —— 左侧白色部分：这次上了四层保险

### 那个白色到底是什么
我把你截图里的颜色量出来了：**`rgb(252,247,253)`** —— 这正是应用主题的 Material 浅色背景（约 `#FFFBFE`）。
也就是说，它不是画面的黑边，而是**"应用背景从缝里露出来了"**：播放页的黑底被某种内缩挤了一下，
后面那层浅色背景就露在最左边。

### 四层保险（任一层生效，白条都不会再出现）
| # | 做法 | 解决的问题 |
| --- | --- | --- |
| 1 | **主题里声明 `windowLayoutInDisplayCutoutMode=always`** | 窗口从创建起就覆盖刘海区（运行时改这个属性常常要等窗口重建才生效，所以写进主题最稳） |
| 2 | 播放页 / 看图页**不吃外壳的内边距** | 横屏时刘海 + 手势区被算进 `innerPadding`，黑底被整体内缩（0.1.30 已做） |
| 3 | **外壳背后垫一层黑底** | 万一还有任何内缩，露出来的也是黑的（本版新增，最直接的一层） |
| 4 | 播放期间 **decorView 背景刷黑** | 覆盖任何没被内容画到的窗口区域（0.1.30 已做，退出自动恢复） |

左右两条黑边本身**不动**——那是「适应屏幕」的正常结果，符合你「宁可留黑边也不裁画面」的偏好。
