## mediagate 0.1.16

按你那张横屏截图改的：**播放时把系统状态栏/导航栏收起来，真正全屏**。

### 改动
- 进播放页**隐藏状态栏与导航栏**（沉浸式全屏），从屏幕边缘上滑可以临时把它们唤出来；
- 离开播放页**自动恢复**，不会让首页也变成没状态栏的样子；
- 只在播放页生效，其它页面照旧。

### 关于两侧黑边
你截图里的视频大约是 4:3，在 2.17:1 的横屏上"适应"显示就会左右留黑。想铺满的话：
播放页底部有 **「缩放」** 档位，点一下切到「**裁剪**」即可填满整屏（会裁掉一点边缘；「拉伸」会变形，按需选）。
默认仍是「适应」，不擅自裁你的画面。

- 包名不变，可直接覆盖安装（含 0.1.15 任务中心修复、0.1.14 任务页来源跟随、0.1.12 字幕闪退根因等）。
