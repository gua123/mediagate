## mediagate 0.1.8

这一版先解决"看不见"的问题，再加你要的排序。

### 新增
- **崩溃日志（诊断）**：设置页新增「诊断与崩溃日志」卡片。App 崩溃时会把**堆栈 + 出事前的日志**
  写进本机，卡片里能直接「查看全文」（可长按复制）。因为自用 sideload 拿不到 logcat，
  这是定位"一播放就闪退"唯一靠谱的办法。
  · 除了 Java 崩溃，还用系统的进程退出记录补上了**原生崩溃**（MediaCodec / ffmpeg / VLC 的 .so 崩了，
    Java 处理器根本不会跑）与 ANR —— 这两种同样会落一份「异常退出报告」，里面带系统记录的 native 轨迹。
- **文件/文件夹排序**：浏览页右上角新增排序菜单——**名称 / 大小 / 修改时间 / 类型** + 升序降序切换。
  目录永远排在最前；大小或时间未知的项永远排最后（升降序都不会翻上去）；选择会记住，换页与重启都保持。

### 说明
- 「单曲循环 / 文件夹（列表）循环」早就有：音频播放页的循环按钮三档 = 不循环 / 列表循环 / 单曲循环。
  如果你要的是**视频**播完下一集这类行为，告诉我，我再加。
- 「视频播放进度保存」也已经有（断点续播）：播放中每 5 秒、暂停时、退出时各写一次，
  再进来会自动跳到上次位置并提示「已从 xx:xx 继续」。**这次的闪退很可能就是它没生效的原因**——
  进程直接没了，什么都写不进去。修掉闪退后再验一次。
- 包名不变，可直接覆盖安装。
