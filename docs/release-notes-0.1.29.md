## mediagate 0.1.29

### 你反馈的两点，都处理了

**① 「我没找到测试内核的地方」→ 现在它就摆在切换路径上**

点「内核」要切到 LibVLC 时，弹窗的**主按钮**变成了「**先测试再切换**」：

- 点它 → 探针在**独立进程**里试跑（不会影响当前播放，也绝不会把 App 带走）；
- **测试通过** → 立刻切过去；
- **测试失败** → 不切，并在弹窗上写明「测试失败：LibVLC 内核在本机起不来（已阻止切换）」；
- 没得到结论（探针进程被系统回收）→ 如实说「可以稍后再试」；
- 想直接切也仍然可以（「仍然直接切换」），但**测过一次不可用之后，就不再给切换按钮**了，只留「重新测试」。

**② 「再次打开时会提示上次闪退是否仍然切换，这很棒」**

这条保留，并且现在和上面的测试打通了：只要测出「本机跑不了」，弹窗就直接变成说明 + 「重新测试」，不再劝你冒险。

### 说明
- 探针**不在启动时跑**（0.1.27 的教训：启动瞬间拉一个可能原生崩溃的进程，用户看到的就是"打不开"），只在你要切 LibVLC 时按需跑；
- 包名不变，可直接覆盖安装。
