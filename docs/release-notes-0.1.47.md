## mediagate 0.1.47 —— 按你的要求做减法：预览图去掉、并发去掉、保留单文件缓存

### 一、预览图功能**整条移除**

滑动调进度时不再抽帧、不再显示缩略图；HUD 只保留「位移量 + 目标时间 / 总时长」。
相关代码（抽帧请求、预览缓存、5 秒桶节流、HUD 图与"预览生成中…"文案）全部删掉，
少一条常驻的失败路径。**外挂字幕、缩略图列表都不受影响**（那是另一条流水线）。

### 二、并发去掉：段改成**一个请求顺序下载**

原来的"段内拆块并发"（4 MB 段拆 4×1 MB 同时下）连同许可池、并发设置一起删除。
理由你也看到了：瓶颈是往返延迟而不是连接数，加并发没收益、却多一层复杂度。
现在每个段 = **一个 Range/读取请求，顺序写完**，行为更好预测。

设置页那两项（并发块数、块大小）也随之消失；「段大小」「预读段数」「测速」保留。

### 三、保留单文件缓存：**正在看的这个文件不会被淘汰**

缓存的淘汰逻辑改成：

- 其它文件按 LRU 照常淘汰（总上限不变）；
- **当前正在读的那个文件的段一律跳过**——它不会被别的文件挤掉；
- 于是"退出去、再进来"同一个文件时，直接读本地缓存，**秒开**。

段大小仍可在设置里调（1/2/4/8 MB，下次连接生效）：想让它更"整文件"就调大一些，
比如 **8 MB 段**，配合缓存上限，一个几 GB 的电影也会留下相当一部分在本地。
