# 0.1.80 发布说明

> 0.1.80 改连接选路：**先内网后外网**——默认先试局域网，连不上自动换公网；
> 原来按 Wi-Fi / 蜂窝 / SSID / 本机网段配置的「选路规则」整块替换成一个「优先网络」开关。

## 先内网后外网

以前多条地址按「人工优先级」挑一个，网络类型（Wi-Fi / 蜂窝）只通过规则间接影响；没有命中规则时
还要并行竞速——公网可能抢在局域网前面。现在统一成一条规则：

1. **局域网地址先排前面**（同一网络内仍按优先级）；
2. 先做一次 **TCP 探测（1.5 秒上限）**：局域网通就用局域网；
3. 局域网不通，**自动改用公网**（反过来也可以，见下）；
4. 全部不通时仍按首选安装，浏览页给出真实错误（超时 / 认证失败等），不会静默退回本地目录。

所以：在家自动走局域网；出门/切蜂窝时不用再手动改地址，会自动走公网。

## 选路规则换成「优先网络」

- 连接编辑器里原来的「选路规则」（传输类型 / Wi-Fi 名称 / 本机网段 / 偏好）整个去掉，
  换成一个开关：**先局域网，连不上再公网**（默认） / **先公网，连不上再局域网**；
- 两个方向都会自动兜底；
- 旧版本存过的规则不会丢：升级后读取它的「偏好」作为优先网络，保存时替换成新的单条设置
  （数据库结构不变，不需要迁移）；
- 连接卡片与设置页的说明同步改成「先内网后外网」，不再显示「竞速」「命中规则」这类旧口径。
