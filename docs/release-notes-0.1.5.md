## mediagate 0.1.5

针对真机那张「SFTP 认证失败」截图做的两处改进——**不是**代码认不出密码，而是让"密码不对"这件事变得可自查。

### 新增
- **连接编辑器里可以「测试一下」**：用**当前草稿**（含刚输入的密码）真跑一遍连通性，**不用先保存**。
  密码框留空时沿用已保存的旧密码（与保存口径一致），所以"到底改没改密码"也测得出来。
  结果是一句能照做的话：通过 → 「测试通过：sftp://…:2222（56 ms）」；失败 → 「测试失败：… — 认证失败 · 账号或密码不正确（DNS 2 ms · TCP 15 ms · 握手 0 ms）」。

### 修复
- **认证失败不再只是一句「加载失败，请重试」**：新增 `BrowserErrorKind.AUTH_FAILED`，
  浏览页遇到认证失败会显示「认证失败：账号或密码不对」并给出指引：
  「到「连接」页点开这条连接 → 编辑，重新输入密码后先点「测试一下」，通过再保存
  （密码框留空表示沿用已保存的旧密码，所以改过服务器密码时必须重新输入）」。

### 说明
- 诊断依据：用工程里的 `RealServerIntegrationTest`（opt-in）在**本机**对着同一台服务器跑，
  6/6 全过（含认证、列目录、逐字节读取）——说明服务器与凭据本身没问题，
  真机上失败的是"App 里存着的那份密码"。所以这一版的重点是让你能一眼确认并就地改。
