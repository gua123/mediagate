## mediagate 0.1.7

修三件一起来的糟心事：「加了连接就回不到本地目录」「选本地目录还要手写路径」「开了全部文件访问也还要手写路径」。

### 修复
- **加了连接之后回不到本地目录**：远端连接一旦「设为当前」，本地目录就退居"备用"（远端优先是既有口径），
  而界面上**原先没有任何回到本地的出口**。现在连接页的「本地目录」卡片在远端生效时会写明状态，
  并给一个大按钮「**改用本地目录（取消当前连接）**」，一点就回去。
- **本地连接的目录不用再手写**：连接编辑器里选「本地」协议后，目录字段旁边直接给三个入口——
  「**选择目录**」（系统 SAF 授权，结果自动填进去）、「**使用内部存储**」（一键填 /storage/emulated/0，
  未授权时会引导去开「所有文件访问」）、「**用已选的目录**」（沿用首页/连接页已经选好的那个）。
- **顺带修掉一个口径不一致的坑**：「本地目录（绝对路径）」那个输入框其实写的是"根路径"（basePath），
  而 App 读的是下面地址里的路径 —— 填了不生效。现在本地连接**只保留一个目录字段**（地址里的那个），
  根路径字段对本地连接直接隐藏，校验也不再拿 basePath 拦人。

### 说明
- 本地连接支持两种形态：SAF 授权的树 URI（`content://…`）与全盘访问下的绝对路径，两者都能保存与浏览。
- 包名不变，可直接覆盖安装。
