## mediagate 0.1.13

你说的对——诊断日志之前只能截图，是我忘了给它出口。这一版补齐。

### 新增
- **诊断与崩溃日志**：卡片与全文对话框都加了三个按钮——
  · 「**复制全文**」：一键写进剪贴板（粘贴到微信发我即可）；
  · 「**另存为文件**」：走系统文件选择器存成 `.txt`（文件名 `mediagate-崩溃报告-时间.txt`），放哪儿你定；
  · 「**分享**」：直接调系统分享（可以选微信/邮件），报告作为纯文本正文。
  正文另外套了可选中容器，长按也能手动选。
- **浏览页的错误提示**（加载失败那一屏）也加了「**复制错误信息**」：把"错误 + 详情 + 处理指引"一起复制，
  以后报错不用截图，直接粘过来。

### 说明
- 包名不变，可直接覆盖安装（包含 0.1.11 的播放页改造与 0.1.12 的字幕闪退根因修复）。
