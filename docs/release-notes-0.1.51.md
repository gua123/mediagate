## mediagate 0.1.51 —— 缓存上限多了"可以自己输入"的窗口

### 加在哪

**设置 → 网络与缓冲 → 缓存上限**，现在是两排：

- 上面仍是四个**快捷档位**：1 GB / 2 GB / 4 GB / 8 GB；
- 下面新增一个**输入框**（写着「自定义（GB）」）+ 「应用」按钮：填 **3** 或 **3.5** 这样的值都行；
- 标题上直接显示**当前上限**（例如「缓存上限：3.5 GB」，不是整 GB 时保留一位小数）。

### 允许的范围

**512 MB ~ 64 GB**，超出或填了非数字会给一句中文提示（例如「最小 512 MB」「请填数字，例如 3 或 3.5」），
而不是默默不生效。

### 生效口径（没变）

**缓存上限与段大小都是"下次连接生效"**——它们决定磁盘上已有段怎么算、淘汰预算多少，中途改会让缓存对不上号；
「预读段数」仍是即时生效。

### 兼容

以前只存过"GB 档位"的版本升级上来：老设置会被按 ×1024 迁移成新口径，**不会突然掉回默认值**。
