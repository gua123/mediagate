# 0.1.113

## 修复

- **SFTP 播放大文件卡死/黑屏**（三个问题一起修的）：
  - 存储层线程池被卡住的读操作占满，导致打开文件时任务排不进去；
  - 从远端读数据时偏移量算错——播放器请求文件尾部，拿到的却是文件开头，
    表现为画面全黑、一直「正在缓冲」；
  - 播放页返回后仍在后台继续播放。
- 现在**返回键 / 左上角关闭 = 停止播放**，**按 HOME / 锁屏 = 后台播放**。

## 说明

- 大文件（非 faststart 的 MP4，索引在文件尾部）现在能正常起播与拖拽。
- 新增「真实 SFTP + 回环代理」的集成测试，防止偏移类问题再次回归。
