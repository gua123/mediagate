## mediagate 0.1.14

修你报的这条：**从本地切到 SFTP 后，任务页的来源还停在本地目录**。

### 根因（两个问题叠在一起）
1. **信号发早了**：任务页原来跟着"当前连接 id"走，而 id 在切换动作**一开始**就变了——
   那一刻远端后端其实还没装好（App 内部生效的根目录仍是本地），任务页于是立刻按新来源去列目录，
   **列到的却是本地后端的内容**，之后再也不会自己刷新。
   现在改成跟着**真正生效的根目录**走，并且**只在后端换好之后**才发信号 → 任务页收到的就是新后端。
2. **路径口径错了**（顺带修掉）：任务页把连接的"根路径"（basePath）当成了要列的目录，
   而后端内部的路径本来就是**相对 basePath** 的（`""`/`/` 就表示 basePath 本身）。
   于是 basePath=/media 时会去列 /media/media。现在统一从**后端根**开始，与浏览页同一口径。

### 顺带
- 远端切不过去时（例如 SFTP 连不上），任务页的来源会**如实退回本地**，
  不会出现"标签写着 SFTP、列的却是本地"这种自相矛盾的状态。

### 说明
- 包名不变，可直接覆盖安装（包含 0.1.11 播放页改造、0.1.12 字幕闪退根因、0.1.13 错误报告导出）。
