## mediagate 0.1.34

### 你问「在哪里查看详情」——老实说：**以前没地方看**

那句「未知错误 · 查看详情」里的「查看详情」**是句空话**：界面上根本没有可点的东西，
它只是错误分类表里的一段说明文字被我直接拼进了提示里。这是我的疏忽，抱歉。

### 现在有两处能看

1. **结果行本身**（0.1.33 起）：分不出来时会直接写「（原始原因：…）」，不用再找入口；
2. **「技术详情」按钮**（本版新增）：点「测试一下」之后，结果下面会出现它，点开是：

```
mediagate 连接测试详情
使用凭据：本次新输入的密码

[1] http://vpn.gua233.top:20005
    结果：失败
    卡在：协议握手（HANDSHAKE）
    分类：服务器内部错误（SERVER_ERROR）— 服务端或反向代理出的问题：看服务日志，或稍后重试
    原始信息：HTTP 502 Bad Gateway
    耗时：DNS 209 ms · TCP 1 ms · 握手 579 ms（合计 789 ms）
```

弹窗里那段文字**可以整段选中，也能点「复制全部」**——你想发给我，直接复制粘贴就行，不用截图。

### 装法

`https://github.com/gua123/mediagate/releases/download/v0.1.34/mediagate-0.1.34.apk`

装好后：**连接 → 新建/编辑连接 → 测试一下 → 点「技术详情」**。
