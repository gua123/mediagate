## mediagate 0.1.17

按你两句要求处理：**「旋转过后留黑边最好」+「不要显示任务栏」**。

### 黑边：保持，不动
默认缩放档位就是「**适应屏幕**」——保持宽高比、完整显示、该留黑边就留黑边，**不会自动裁你的画面**。
（想铺满时才需要手动把底部「缩放」切到「裁切填充」，那是你的选择，我不会替你改默认。）

### 任务栏：继续收干净
- 0.1.16 起播放页已经隐藏**状态栏与导航栏（含底部手势条）**，从边缘上滑可临时唤出；
- 这一版再补两件事：
  · **从桌面切回来、锁屏解锁、或你上滑把栏唤出过之后，会自动再收起一次**
    （只做一次隐藏的话，系统会在这些时机把栏放回来，看起来就像"任务栏又冒出来了"）；
  · **图片查看器也一起全屏**（看图同样是"不要任务栏"的场景）。
