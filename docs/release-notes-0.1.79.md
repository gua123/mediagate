# 0.1.79 发布说明

> 0.1.79 加一个连接管理的小功能：**给已有连接补上「另一条网络」的地址**（局域网 ↔ 公网）。

## 新：一条连接可以轻松挂两条网络

同一个连接的多个地址本来就会被当作**同一台服务器**（缓存共用、按当前网络自动选路），
但以前补地址要「编辑 → 添加地址 → 重新选标签、填协议、填端口」，两条网络只有主机名不同，很啰嗦。

现在：

- **连接卡片上直接补**：这条连接只填了局域网（或只有公网）时，卡片上会出现「**补一条公网地址**」/「**补一条局域网地址**」，
  点进去编辑器已经把协议、端口、优先级都复制好了，**只填主机名**即可；
- **编辑器里也能加**：每个地址块下方有「**再加一条同一服务器的另一条网络**」；
- **新地址标签自动取还缺的那条**：只有局域网就默认公网、只有公网就默认局域网（以前总是默认公网）；
- 地址区下方加了一句说明：「同一个连接的多个地址会被当作同一台服务器：缓存共用、按当前网络自动选路；局域网和公网各加一条即可。」

本地目录连接不显示「补一条网络」入口。

## 验证
