## 3. 已实现能力（对照需求）

- **R1 本地三类媒体**：浏览（列表/进入子目录/返回上级/下拉刷新）→ 图片进查看器（缩放/拖动/双击/翻页）、音频进播放页（进度拖拽/上下首/倍速/循环）。
- **R2/R12 本地双模式**：SAF 选目录（持久化授权）与「所有文件访问」全盘浏览，两条路径都可用、可切换；未授权时给中文引导不崩。
- **R5 缩略图**：视频抽帧（MMR 主策略 + 10%/1%/25% 换位重试 + FFmpeg 兜底）、图片采样重编码预览、音频内嵌封面；内存 + 512 MB 磁盘两级缓存、负缓存、并发上限 3（SFTP/FTP 降到 2）、离屏取消。
- **R18 音频侧**：MediaSessionService 前台服务 + 通知栏/锁屏控制、音频焦点被抢占自动暂停、耳机拔出暂停、后台/息屏继续播放、断点续播（DataStore，最近 200 条）。

## 5. 已知限制（已记录，后续里程碑处理）

- **视频的后台播放**（R18 中「视频切后台不中断」）需与画中画、视频播放页联动，留到 M2/M8。
- **通知栏封面**（MediaMetadata artwork）未接，当前通知只有标题与文件名。
- **音频封面**只取 MMR 内嵌图，未做同目录 `cover.jpg` 兜底。
- **缩略图负缓存**在内存（未落 Room `thumb_meta`），进程重启后失败项会重试一次。
- **图片查看器**单张上限 64 MB（超出给中文提示），未做分块解码。
- **媒体内核**尚未抽象：`:media:engine` 只挂了 Media3/LibVLC 依赖，PlayerEngine 抽象与回环代理是 M2 的内容（音频播放当前直接用 ExoPlayer）。
- **DI 未引 Hilt**：用手写 `AppContainer` + CompositionLocal 注入（见 plan 记录的理由），M2 视注入规模再评估。
