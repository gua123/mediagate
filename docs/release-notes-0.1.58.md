## mediagate 0.1.58 —— 记住上次播放时的横屏/竖屏

### 现在的行为

- **进播放页**：直接套用**上一次播放时的方向**（上次横屏就横屏、上次竖屏就竖屏）；
- **点顶栏的旋转按钮**：切换方向，并**立刻记住**这次的选择；
- **离开播放页**：方向交还系统（首页/浏览页不会被锁死在横屏）——只有"播放时"的方向被记住；
- **从没记录过**（新装/清过数据）：保持旧行为，跟随系统。

### 为什么"离开就恢复"

你要的是"记住**播放时**是横屏还是竖屏"，而不是"把整个 App 锁在横屏"。所以退出播放页仍然恢复跟随系统，
下次再进播放页时按记住的那个方向走。
