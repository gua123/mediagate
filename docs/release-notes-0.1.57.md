## mediagate 0.1.57 —— 控制层：有操作绝不隐藏 + 隐藏秒数可调

### 你提的两条，现在是这样

**① 有操作时不能隐藏**

以前只有"拖进度条 / 字幕面板开着 / 暂停"这几种情况会阻止隐藏，**点芯片、开列表、拖到一半手指还按着**这些都不算——
所以会出现"正在操作，控制层自己跑了"。现在改成：**屏幕上任何触摸（按下或拖动）都会让计时重新开始**，
手指还按着就一直不隐藏；只要有任何面板/弹窗开着、正在拖进度、或者视频处于暂停/结束状态，**都不会倒计时**。

**② 无操作多少秒才隐藏 —— 现在可以自己定**

**设置 → 播放 → 控制层自动隐藏**：

| 档位 | 行为 |
| --- | --- |
| **3 秒**（默认，与旧版一致） | 播放中无操作 3 秒收起控制层 |
| **5 秒** / **10 秒** | 更宽容，适合边看边调 |
| **不自动隐藏** | 控制层一直在，只有你点画面才收 |

改完**下次进播放页生效**（正在播的那条要退出重进）。

### 顺带明确的规则

- **暂停 / 播放结束 / 出错时不会自动隐藏**（这时控制层上有你需要的操作与信息）；
- 画中画里不显示我们的控制层，自然也不涉及隐藏；
- 点一下画面仍是"显示/收起"的手动开关。
