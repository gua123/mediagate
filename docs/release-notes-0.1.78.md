# 0.1.78 发布说明

> 0.1.78 只修一件事：**公网/弱网下「返回上一个文件夹一直转圈」**。

## 修：返回上一级不再无限转圈

**现象**：用公网地址时，从子目录返回上一级，页面一直转圈不回内容（有时等很久也不报错）。

**原因**：返回上一级会重新列一次目录；公网链路上这次请求可能卡在底层的阻塞式网络调用里（DNS / TLS / 服务端迟迟不响应）。
原来的「15 秒超时」只包在协程层：**协程取消打断不了阻塞调用**，超时要等阻塞调用自己返回才生效——
实测「2000 毫秒的阻塞调用套 100 毫秒超时」实际要 2059 毫秒才返回，所以界面就可能一直转。

**修法**：把阻塞调用放到独立作用域里跑，调用方**到点就返回**（元数据 15 秒 / 单次读 30 秒），不再被它拖住；
超时归类为「网络超时」，界面给出**重试**按钮与提示（换个网络再试；开着 VPN/代理时也可能这样），错误信息可复制。

**边界**：被放弃的底层调用无法强杀（协程取消对阻塞 socket 无效），它会由底层库自己的 socket 超时收尾；
我们保证的是**界面/播放器不再为它无限等待**。

## 其它

- 局域网下行为不变（请求本来就很快，一般不会触发超时）。
- 这是对 0.1.46「超时保险」的补强：那次只解决了「调用最终会返回」的情况，这次解决「调用一直不返回」的情况。
