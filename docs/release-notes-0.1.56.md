## mediagate 0.1.56 —— "播放时的列表"统一跟随你选的排序（补齐音频与图片）

### 你提醒的这件事，我核实后的结论

- **视频播放页的队列**（含「列表」面板、「第 N / M 集」、上一集/下一集）：0.1.54 起**已经**跟随排序设置
  （如果还看到旧顺序，多半是那一版还没装上）；
- **音频播放页的队列**（上一首/下一首、连播顺序）：之前**没有**跟随排序——模块内部按名称排完就定死了；
- **图片查看器的左右滑动顺序**：同样**没有**跟随。

这一版把后两处也接上同一个排序口径（:app 在过滤之后统一按你的排序设置再排一次），
于是**浏览页、视频页、音频页、看图页看到的顺序完全一致**。

顺手在两处"模块内部按名称排"的函数上加了醒目注释（名称排序只是兜底，最终顺序以调用方那次为准），
免得以后有人以为顺序在那儿定死了——这正是你这次提醒暴露出来的那类"两处各算一遍"的问题。

### 排序在哪改

浏览页右上角的排序菜单（名称 / 大小 / 修改时间 / 类型 + 升降序），改完**全应用的列表与队列一起变**。
