## mediagate 0.1.18

修你报的这条：**点右上角「内核」切内核会闪退**。

### 根因
切换内核时，代码只把"建内核"这一步包在了兜底里，而**新内核接管现场的那一整段**（设置解码档位 → 缩放档位 →
装载媒体 → 准备 → 跳到原位置 → 倍速 → 字幕 → 起播，以及把播放会话绑到新内核上）**全都在兜底之外**。
切到 LibVLC 时这条链上任何一步抛异常（建实例、回环代理、画面挂载…），都会顺着协程冒到默认处理器
→ 整个 App 闪退。

### 修法
- **接管现场这一段整体兜底**：失败时释放半成品内核、把界面置为错误态并**显示中文原因**，App 不再消失；
- **失败后状态归零**：旧内核已释放、新内核没起来，界面不该还显示"暂停"按钮（`playing/buffering` 一并清零）；
- 顺带：这条路径现在会在诊断日志里留下原因，若切到 LibVLC 仍然失败，把「诊断与崩溃日志」的全文发我，
  我就能针对 VLC 那条路继续修（而不是只知道"闪退了"）。

### 说明
- 包名不变，可直接覆盖安装（含 0.1.17 全屏、0.1.15 任务中心修复等）。
