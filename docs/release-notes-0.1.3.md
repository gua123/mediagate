## mediagate 0.1.3

小版本，收掉两处"用起来别扭"的地方。

### 改进
- **连接页也能管本地目录了**：新增「本地目录」卡片（当前模式 + 路径 + 「选择目录」/
  「使用内部存储」或「开启全部文件访问」/「清除」）。此前只有首页能选本地目录，
  于是在连接页想换成手机里的目录时没有入口，得绕回首页。
- **首页根目录卡片说清楚"现在用的是谁"**：远端连接生效时，卡片顶部直接写
  「正在使用远端连接：xxx」，本地那项改称「备用本地目录」并说明"清除它不会断开远端"。
  此前远端生效时卡片仍按本地口径显示，容易误以为在看本地目录。

### 说明
- 包名与 0.1.1/0.1.2 相同，可直接覆盖安装。
- 剩余未做项都是"设计取舍"或"要真机才能验"的（R4 不承诺毫秒级拖拽、ASS 仅基础样式、
  Media3 无字幕延迟 API 改用 Compose 覆盖层等），详见 docs/验收记录-M2-M8.md 第 5 节。
