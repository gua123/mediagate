## mediagate 0.1.60 —— 全屏任意位置都能左右滑动调进度

### 问题出在哪

0.1.53 加"左侧滑亮度 / 右侧滑音量"时，我把屏幕**按位置切成了三个区**：左 1/3、中间 1/3、右 1/3，
只让**中间**那块处理横滑调进度 ⇒ 你在左右两侧横滑就没反应了（这其实是我把你早先要的"横滑调进度"给缩小了，抱歉）。

### 现在按"方向"判定，不再按"位置"切

一个手势处理器搞定三件事：

| 你的动作 | 结果 |
| --- | --- |
| **横向滑动**（屏幕**任何位置**，含最左最右） | **调进度**（中央显示目标时间） |
| 左侧**竖向**滑动 | 调亮度 |
| 右侧**竖向**滑动 | 调音量 |
| 中间区域**竖向**滑动 | 不做任何事（避免和横滑抢事件） |

判定方式：手指移动超过系统触摸阈值后，看**哪个方向占优**——横向占优就是调进度，
纵向占优才按起始位置区分亮度/音量；判定一旦成立就**整段手势只做这一件事**，不会中途跳来跳去。
