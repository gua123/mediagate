## mediagate 0.1.53 —— 三条新需求：亮度手势 / 音量手势（上限 200%）/ 首次打开更快

### ① 播放时左侧上下滑动 = 调亮度

- 屏幕**左 1/3** 区域上下滑动：向上变亮、向下变暗，中央显示「亮度 40%」；
- **不播放时自动恢复**：退出播放页立刻交还系统亮度（不会改掉整个手机的亮度）；
- **下次播放记住**：调完的值存下来，下次进播放页直接用这个亮度。

### ② 播放时右侧上下滑动 = 调音量，上限 200%

- 屏幕**右 1/3** 区域上下滑动，中央显示「音量 120%」；
- **上限 200%**：0–100% 走播放器自身音量，**100%–200% 用系统增益补**（Media3 内核用 LoudnessEnhancer，200% ≈ +6 dB；LibVLC 内核本来就支持到 200）。个别机型/音轨不支持音效链时会**如实退回 100%**，不影响播放；
- 音量同样**记住**：换内核、退出重进都不会掉回 100%。

### ③ 新视频"第一次打开要等很久"

这次做了**打开即预取**：以前是"起播时才开始拉第一段"，现在是**一确定要播这个文件，就在后台先把开头两段（约 8 MB）拉进缓存**，Media3 要数据时往往已经在本地了；段级"单飞"保证预取与起播不会重复拉同一段。

> 想更激进可以自己在 **设置 → 网络与缓冲** 里调：内网把**段大小**调到 **8 MB**、**预读段数**调到 **3–4**；公网建议保持默认（段太大反而等得久）。

### 手势分布（互不打架）

| 区域 | 手势 |
| --- | --- |
| 左 1/3 | 竖直：亮度 |
| 中间 1/3 | 横滑：进度 |
| 右 1/3 | 竖直：音量 |
